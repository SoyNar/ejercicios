#  Generation - Ejercicios de JavaScript

Este repositorio contiene todos los ejercicios realizados en la clase de JavaScript de Generation. El objetivo principal es tener los ejercicios centralizados en un solo lugar y contar con una mejor organización para dar seguimiento al aprendizaje.

---

## 📂 Contenido del Repositorio

### 1. FizzBuzz
Programa que recorre los números del 1 al 1000 con un bucle `for` e imprime mensajes específicos en función de sus divisibilidad mediante sentencias `if` / `else`.

### 2. Calculadora Básica
Programa que recibe dos números y un operador (`+`, `-`, `*`, `/`) como argumentos para realizar operaciones matemáticas elementales.

### 3. Calculadora Mejorada (Con Pruebas Automáticas)
Programa interactivo modularizado en Node.js que implementa funciones matemáticas y lógicas validadas mediante un ejecutor de pruebas automático (`test.js`):

- `sumarMultiplesNumeros(numeros)`: Suma un arreglo de números.
- `multiplicarMultiplesNumeros(numeros)`: Multiplica un arreglo de números en secuencia.
- `esPar(numero)`: Determina si un número es un entero par.
- `esEntero(numero)`: Valida si un número es entero.
