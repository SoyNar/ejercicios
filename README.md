# Ejercicios de JavaScript

## FizzBuzz
Programa que recorre los números del 1 al 1000 con un bucle `for`. Usando `if / else if / else` evalúo si cada número es divisible por 3, por 5, por ambos, o ninguno, e imprimo "Fizz", "Buzz", "Fizzbuzz" o el número según corresponda.

## Calculadora
Programa que recibe dos números y un operador (`+`, `-`, `*`, `/`) como argumentos por línea de comandos. Con `if / else if / else` comparo el operador y realizo la operación correspondiente. También manejo el caso de división por cero y de operador inválido.
